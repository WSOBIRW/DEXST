
# DEXST

**DEXST** — самостоятельная русскоязычная среда разработки с детерминированным AI-контуром.  
AI не получает прямой власти над проектом: каждый его ответ проходит проверку через **DAIC** перед тем, как стать действием.

## Что внутри

- **DAIC** — детерминированное ядро AI-интеграции.  
- **DEE** — управление допустимыми вариантами (гипотезы, патчи, анализ).  
- **NEC** — система необходимости: следующее состояние выводится, а не выбирается.  
- **Capsule Engine** — изолированная проверка каждого AI-ответа.  
- **Safety Gate** — финальный допуск: `ALLOW`, `DROP`, `REQUIRE_APPROVAL`.  
- **AI-память** — изолирована по проектам (`.dextr/ai_memory/`).  
- **Русский интерфейс** — меню, панели, командная палитра.  
- **Workspace bootstrap** — автоматическое создание `.dextr/` при открытии папки.  
- **Отсутствие телеметрии и облачных служб.**  
- **Поддержка локального AI (Ollama)** — работа без интернета и API-ключей.

## Формула проекта

```text
AI предлагает.
DEE ограничивает пространство решений.
NEC выводит обязательные состояния.
Capsule проверяет действие.
Safety Gate допускает или блокирует.
Создатель утверждает.
```
