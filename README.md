# DEXTR STUDIO

**DEXTR STUDIO** — самостоятельная среда разработки на временном техническом фундаменте.

## Статус
Ранняя разработка. Форк используется как основа для построения собственной среды.

## Особенности
- Русский интерфейс (в процессе)
- Отключены телеметрия и встроенные AI-провайдеры
- Встроенная инициализация рабочего пространства DEXTR (`.dextr/`)
- Будущая детерминированная AI-интеграция через DAIC

## Лицензия
Исходный код основан на Zed, соблюдайте условия исходных лицензий (GPL/AGPL/Apache 2.0).
