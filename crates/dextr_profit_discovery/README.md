# DEXTR Profit Discovery

Минимальное Rust-ядро исследования экономических отношений через прибыль.

## Назначение

Ядро представляет экономические формы стоимости как объекты, а их преобразования,
передачу, обеспечение, финансирование и другие связи как направленные отношения.
На этой карте можно находить структурные комбинации и проверять связанные с ними
гипотезы о прибыли.

## Что реализовано

- типизированные формы стоимости: наличные, банковские остатки, электронные деньги,
  долговые требования, акции, облигации, криптоактивы, стейблкоины, CBDC, NFT,
  токены, производные инструменты, страховые требования и другие формы;
- направленная карта экономических объектов и отношений;
- детерминированный поиск цепочек из двух отношений A → B → C;
- проверка ссылочной целостности гипотез;
- расчёт базовой и вероятностно-взвешенной чистой прибыли;
- учёт требуемого капитала и альтернативной стоимости капитала;
- ранжирование отдельно внутри каждой валюты, без некорректного сравнения разных валют;
- проверки некорректных и отрицательных значений;
- журнал доказательств с источником, издателем, временем получения и контрольным отпечатком;
- привязка наблюдаемых фактов к экономическим объектам и конкретным доказательствам;
- фиксация попыток опровержения гипотез с обязательными доказательствами;
- запрет перезаписи записей журнала по существующему идентификатору.

## Расчёт

Базовая чистая прибыль:

`выручка - прямые затраты - операционные затраты - финансирование - налоги`

Ожидаемая чистая прибыль:

`(базовая прибыль × вероятность успеха - возможный убыток × вероятность неудачи) - альтернативная стоимость капитала`

Вероятности хранятся в базисных пунктах: 10 000 = 100%.
Денежные значения хранятся в минимальных единицах валюты и не используют числа с плавающей точкой.

## Запуск тестов

```sh
cargo test -p dextr_profit_discovery
```

## Доказательная дисциплина

Запись факта без доказательства запрещена. Ссылка на доказательство должна существовать в журнале до регистрации факта. Для каждого источника фиксируются контрольный отпечаток и временные метки. Исправление данных оформляется новой записью, а не перезаписью истории.

Журнал подтверждает происхождение сведений, но не истинность источника. Независимость, достоверность, полнота и юридическая применимость источников должны оцениваться отдельными процедурами.

## Ограничения первой версии

- структурный кандидат не считается коммерческой возможностью автоматически;
- расчёты являются оценками гипотез, а не реализованной прибылью;
- внешние источники, курсы валют, рыночные данные и юридические реестры пока не подключены;
- автоматическая проверка контрольных отпечатков исходных файлов и подписи издателя пока не реализована;
- статистическое обнаружение аномалий по временным рядам пока не реализовано;
- нет дисконтирования денежных потоков по датам;
- нет модели ликвидности, налоговой юрисдикции, контрагентского риска и регуляторных ограничений;
- синтетические тестовые данные не являются рыночным доказательством.

## ЧЕМ НЕ ЯВЛЯЕТСЯ

- торговым роботом;
- биржей, банком, платёжной системой или криптокошельком;
- инвестиционной рекомендацией;
- прогнозом гарантированной доходности;
- системой автоматического размещения капитала;
- закрытым перечнем допустимых финансовых форм.

Новые формы стоимости и отношения должны добавляться без изменения базового принципа карты.
